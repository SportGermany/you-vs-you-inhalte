# You vs You: Lektionen

Öffentliche Lektionspakete für die App **You vs You**. Hier liegen nur Lerninhalte (Wissenstexte und Quizfragen), keine persönlichen Daten.

Die App lädt `index.json` und alle geänderten `paket-*.json` automatisch im WLAN.
Die Dateien werden automatisch erzeugt. Bitte nicht von Hand bearbeiten.
